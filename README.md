# 민병주 포트폴리오

Spring Boot를 중심으로 실시간 시스템과 웹·모바일 서비스를 개발한 프로젝트 포트폴리오입니다.

## 포트폴리오 사이트

[https://portfoilo-nine-liard.vercel.app/](https://portfoilo-nine-liard.vercel.app/)

## 대표 프로젝트

- **AI 스마트 안전 관제 시스템**: 인증·회원가입, MQTT 이벤트 중계, STOMP 실시간 알림, Android FCM 담당
- **Mercenary**: 1인 개발 축구 용병 매칭 플랫폼, Redis 캐시·Redisson 분산 락·부하 테스트
- **OpenCloset**: 위치 기반 P2P 의류 대여 서비스 백엔드
- **Runner's High**: 건강 데이터 기반 러닝 크루 매칭 서비스

## 주요 기술

Java, Spring Boot, Spring Security, JWT, PostgreSQL, MariaDB, MySQL, Redis, MQTT, STOMP, React, TypeScript, NestJS, Docker
